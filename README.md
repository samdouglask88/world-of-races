# World Of Races

Um mod de Minecraft que adiciona raças de fantasia jogáveis/habitantes ao mundo (elfo, humano, anão, orc, gnomo, troll), inspirado em RPGs de fantasia como World of Warcraft.

## Status
Em desenvolvimento inicial — começando pela implementação da raça humana.

## Requisitos
- Minecraft 1.20.1
- Forge 47.4.10 ou superior
- Java 17

## Como compilar/rodar
No Windows, use:

```
.\gradlew build
.\gradlew runClient
```
